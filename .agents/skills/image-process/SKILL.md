# Обработка картинок (локально, бесплатно, без сети)

## Правки владелицы - читаешь ДО работы

1. `team/agents/dizajner/memory.md` - решения и предпочтения владелицы по визуалу,
   раздел «Паттерны» обязателен: как она принимает и что бракует.
2. `team/agents/dizajner/knowledge/INDEX.md` - карта базы, что открывать под задачу.
3. `team/agents/dizajner/knowledge/formats.md` - размеры под площадки.

**Новая правка от неё - строка в память в тот же заход.** Правка, которая меряется числом
(размер, отступ, цвет), идёт в команду или пресет ниже, а не в текст.

## Инструменты

- `magick` - ImageMagick, ставится на этапе 2 установки (`brew install imagemagick`).
  Нет - `which magick` пуст, зови Технаря, сам не ставишь.
- `ffmpeg` - кадры из видео и, если нужно, картинки в ролик.

Всё работает на её маке, наружу ничего не уходит. Облачных обработок (удаление фона,
апскейл, дорисовка) в офисе нет: если просят «убери фон» или «увеличь в 4 раза»,
говоришь честно, что этого офис пока не умеет, и предлагаешь, что можно сделать локально
(кроп, замена на однотонный фон, перегенерация через `image-gen`).

## Форматы инстаграма (из `formats.md`)

| Куда | Размер | Gravity при кропе |
|---|---|---|
| Рилс, сторис, обложка рилса | 1080x1920 (9:16) | center (лицо и текст по центру: в сетке видно центральный квадрат) |
| Карусель, пост в ленту | 1080x1350 (4:5) | center |
| Квадрат в ленту | 1080x1080 (1:1) | center |
| Аватар | 320x320 | center |

Экспорт: JPG качество 85-92 для фото, PNG для картинок с текстом и плашками. Файл тяжелее
8 МБ инстаграм пережмёт сам и картинка станет хуже.

## 1. Ресайз и кроп под формат

```bash
# вписать по ширине (пропорции сохраняются)
magick вход.jpg -resize 1080x вых.jpg

# точный формат с обрезкой лишнего (заполнить и обрезать по центру)
magick вход.jpg -resize 1080x1350^ -gravity center -extent 1080x1350 вых.jpg

# то же, но важное сверху (лицо в верхней трети)
magick вход.jpg -resize 1080x1920^ -gravity north -extent 1080x1920 вых.jpg

# вписать целиком на однотонный фон, без обрезки (когда обрезать нельзя)
magick вход.jpg -resize 1080x1350 -background '#f4efe9' -gravity center -extent 1080x1350 вых.jpg

# ручной кроп: ширина x высота + смещение от левого верхнего угла
magick вход.jpg -crop 1080x1350+0+200 +repage вых.jpg
```

## 2. Нарезка одной картинки под все форматы

```bash
SRC="results/kartinki/исходник.jpg"
OUT="results/kartinki/nabor-$(date +%Y-%m-%d)"
mkdir -p "$OUT"
magick "$SRC" -resize 1080x1920^ -gravity center -extent 1080x1920 "$OUT/rils-9x16.jpg"
magick "$SRC" -resize 1080x1350^ -gravity center -extent 1080x1350 "$OUT/karusel-4x5.jpg"
magick "$SRC" -resize 1080x1080^ -gravity center -extent 1080x1080 "$OUT/kvadrat-1x1.jpg"
ls "$OUT"
```

Проверка глазами до отдачи: главный объект не срезан ни в 9:16, ни в 1:1; для
вертикальных форматов попробуй `-gravity north`, если лицо ушло вниз.

## 3. Конверт и сжатие

```bash
magick вход.png вых.jpg                       # смена формата
magick вход.jpg -quality 88 вых.jpg           # сжать фото
magick вход.png -strip -quality 90 вых.jpg    # убрать метаданные и сжать
magick вход.heic вых.jpg                      # фото с айфона в jpg
magick mogrify -resize 1080x -quality 88 -path "$OUT" results/kartinki/proby/*.jpg   # пачкой
```

## 4. Слайды карусели: фон + текст плашкой

Текст рисуем локально, не в генераторе (там он кривой). Шрифт берёшь из
`work/firmennyj-stil.md`; пока там пусто - системный `Helvetica` и один вариант на пробу.

```bash
# одноцветный фон под слайд
magick -size 1080x1350 xc:'#f4efe9' fon.png

# текст по центру с отступами (поле 960 px, автоперенос по словам)
magick fon.png \
  \( -size 960x -background none -fill '#2b2b2b' -font Helvetica -pointsize 64 \
     -gravity center caption:'Отёки под глазами: что реально помогает' \) \
  -gravity center -composite slajd-1.png

# плашка под текст поверх фото (полупрозрачная)
magick foto.jpg -resize 1080x1350^ -gravity center -extent 1080x1350 \
  \( -size 1080x420 xc:'rgba(255,255,255,0.82)' \) -gravity south -composite \
  \( -size 960x -background none -fill '#2b2b2b' -font Helvetica -pointsize 56 \
     -gravity center caption:'Три ошибки в уходе осенью' \) \
  -gravity south -geometry +0+90 -composite slajd-2.png
```

Правило одного слайда: одна мысль, воздух, крупный читаемый шрифт (см. `styles.md`).
Перед серией показываешь один слайд и спрашиваешь «так или не так?».

## 5. Коллаж и монтаж слайдов

```bash
# два фото рядом (до/после), выровнять по высоте
magick do.jpg posle.jpg -resize x1350 +append -resize 1080x1350^ -gravity center -extent 1080x1350 do-posle.jpg

# сетка 2x2 с отступами
magick montage 1.jpg 2.jpg 3.jpg 4.jpg -tile 2x2 -geometry 520x520+10+10 -background white setka.jpg

# один PDF из слайдов (посмотреть карусель целиком на телефоне)
magick slajd-*.png karusel.pdf
```

## 6. Кадр из видео и картинка в ролик (ffmpeg)

```bash
# кадр на 3-й секунде под обложку
ffmpeg -y -ss 00:00:03 -i dubl.mp4 -frames:v 1 obl.png

# картинка в 5-секундный вертикальный клип (под вставку в рилс)
ffmpeg -y -loop 1 -i slajd-1.png -t 5 -vf "scale=1080:1920:force_original_aspect_ratio=decrease,pad=1080:1920:(ow-iw)/2:(oh-ih)/2" -r 30 -pix_fmt yuv420p slajd-1.mp4
```

## Куда класть и как отдавать

Готовое - в `results/kartinki/` (карусель - в `results/karuseli/<дата>-<тема>/`), панель
покажет владелице. Отдаёшь путь и одну строку: что сделано и в каком размере.
Промежуточные пробы после выбора удаляешь.
