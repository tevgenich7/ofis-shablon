# Creative Brief - визуальный бриф + промт

## Вход
- Что делаем (обложка рилса / слайды карусели / сторис / фото процедуры или кабинета / иллюстрация к посту)
- Для чего (рилс / карусель / сторис / пост)
- Стиль (см. `team/agents/dizajner/knowledge/styles.md`) - если не указан, определи по типу задачи или спроси
- Текст на визуале (от Копирайтера) - если есть

## Шаги

### 1. Определи стиль
Какой стиль (см. `team/agents/dizajner/knowledge/styles.md`)? От этого зависит ВСЁ: палитра, шрифты, язык, инструмент.
Пока `work/firmennyj-stil.md` пустой, палитру не выдумывай: цвет от её фото и кабинета, один вариант на пробу и вопрос «так или не так?».

### 2. Определи формат
Прочитай `team/agents/dizajner/knowledge/formats.md`. Выбери размер по площадке:
- Рилс, сторис, обложка рилса: 1080x1920 (9:16), лицо и текст по центру
- Карусель, пост в ленту: 1080x1350 (4:5)
- Квадрат в ленту: 1080x1080 (1:1)
- Аватар: 320x320 (1:1)

### 3. Собери концепцию
- **Настроение**: 3-5 слов (не «красиво», а «тревожный, с проблеском надежды»)
- **Главный элемент**: что в центре кадра
- **Композиция**: минимализм / симметрия / диагональ
- **Палитра**: hex-коды из стиля (не «тёмный синий», а конкретный hex)

### 4. Напиши промт
Структура: `[описание] + [фон/палитра] + [главный элемент] + [язык стиля] + [композиция] + no text + --ar [формат]`.

**Пример - фон под слайд карусели (текст наложим потом):**
```
[описание], soft daylight, clean skincare clinic background, warm neutral palette [hex из стиля], shallow depth of field, calm and airy composition, no people, no text --ar 4:5
```

**Пример - обложка рилса про процедуру:**
```
close-up of hands in nitrile gloves applying serum to a cheek, natural skin texture, soft window light, clean minimal treatment room, warm neutral tones [hex из стиля], realistic photo, no text --ar 9:16
```

> Палитру бери из её стиля (`team/agents/dizajner/knowledge/styles.md`, а когда заполнен - `work/firmennyj-stil.md`), не хардкодь чужие hex. Кадр с её лицом - только через ИИ-фотосессию (`image-gen`, `foto-sessiya.py`) и с её разрешения.

### 5. ТЗ для фрилансера (если нужно)
```
## Визуальное задание: [название]
Формат: [размер px, ratio]
Стиль: [см. styles.md]
Фон: [hex]
Главный элемент: [что]
Текст: [макс 7 слов или "нет"]
Цвета: [hex-коды]
Шрифт: [название + начертание]
Настроение: [3-5 слов]
Запрещено: [список]
```

### 6. Self-check
- [ ] Стиль определён, коды не смешаны
- [ ] Hex-коды из стиля (не приблизительные)
- [ ] Формат и размер указаны
- [ ] Промт готов к копированию
- [ ] Запрещённые стили исключены

### 7. Автоматическая генерация (если запрошено)
Если задача включает «сгенерируй» / «сделай картинку» (а не только бриф):
1. Запусти `../image-gen/SKILL.md` с готовым промтом
2. Отдай 2 варианта
3. Дождись её выбора
4. При необходимости подгони под формат, наложи текст, нарежь под все размеры через `../image-process/SKILL.md`

## Выход
Структурированный бриф:
1. Стиль + формат + платформа
2. Концепция (настроение, элемент, палитра)
3. Промт для AI-генерации (готов к копированию)
4. ТЗ для фрилансера (если запрошено)

## Пример

**Вход:** «Обложка рилса про отёки под глазами, светло и спокойно»

**Выход:**
```
Стиль: светлый, тёплые нейтральные тона (до заполнения work/firmennyj-stil.md - проба) | Формат: 1080x1920 (9:16)
Настроение: спокойное, утреннее, чистое
Элемент: крупный план области под глазом, прохладный роллер в руке, мягкий свет из окна

Промт:
close-up of the under-eye area, a cool jade roller held gently, soft morning window light, clean pale background, warm neutral tones, natural skin texture, realistic photo, centered composition, no text --ar 9:16
```
