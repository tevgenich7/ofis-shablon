# Установка офиса на твой мак

Это делается один раз, около часа: четыре шага из этого файла занимают примерно полчаса,
ещё столько же - то, что офис доделает с тобой в разговоре. Дальше офис открывается
кнопкой с рабочего стола.

**Главное, что стоит знать:** всю установку офис проведёт сам. Как только дойдёшь до шага 3
и напишешь «привет», в разговор вступит Технарь - помощник, который объясняет по шагам
и ждёт тебя на каждом. Ничего не надо запоминать заранее: этот файл нужен только чтобы начать.

Если что-то не получается на любом шаге, напиши Тарасу, он подключится к экрану.

---

## Шаг 1. Программа, на которой живёт офис (15 минут)

Офис - это команда помощников. Программа - место, где ты с ними разговариваешь.
Мы ставим **Codex**, он входит в подписку ChatGPT.

Сначала проверь, что подписка ChatGPT Plus оплачена на твою почту. Без неё офис не запустится.

1. Открой «Терминал» (⌘+Пробел, набери «Терминал», Enter). Это чёрное окно, в него
   вставляют строки. Ничего страшного в нём нет.
2. Вставь строку и нажми Enter:

```
npm install -g @openai/codex
```

   Если пишет, что `npm` не найден: зайди на https://nodejs.org, нажми зелёную кнопку LTS,
   установи, потом повтори строку.

   Если в ответ бежит красный текст со словами `EACCES` и `permission denied` - это не
   поломка, а права: программа ставится в системную папку, а туда нужен пароль. Вставь
   ту же строку со словом `sudo` впереди:

```
sudo npm install -g @openai/codex
```

   Попросит пароль от мака. При вводе пароль не виден - так задумано, просто набери и Enter.

3. Вставь `codex` и нажми Enter. Выбери вход через аккаунт ChatGPT, откроется браузер,
   подтверди. Вернись в Терминал.

Проверка: набери `codex --version` - появится номер версии.

## Шаг 2. Программы для роликов и каруселей (10 минут)

Первая склеивает видео, вторая собирает картинки в слайды. Без них Монтажёр и Дизайнер
расскажут, как сделать, но сам файл не соберут.

1. Вставь строку и нажми Enter:

```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

   Попросит пароль от мака. При вводе пароль не виден - так задумано, просто набери и Enter.
   Может попросить установить Xcode Command Line Tools - соглашайся. Это полтора гигабайта,
   идёт до пятнадцати минут, экран в это время кажется застывшим. Так и должно быть, не прерывай.

2. Когда закончит, вставь эту строку. Она ничего не выведет в ответ - это правильно:

```
echo >> ~/.zprofile && echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile && eval "$(/opt/homebrew/bin/brew shellenv)"
```

   Без неё следующая строка ответит `command not found: brew`.

3. Потом вставь:

```
brew install ffmpeg imagemagick
```

   Идёт несколько минут, по экрану бежит текст. Так и должно быть.

Проверка: `ffmpeg -version` и `magick -version` покажут номера версий.

## Шаг 3. Первое открытие офиса (5 минут)

1. Перейди в папку офиса. Папка `anna-kosmetolog-ofis` лежит на рабочем столе:

```
cd ~/Desktop/anna-kosmetolog-ofis
```

   Не сработало - значит папка в другом месте. Набери `cd `, поставь пробел и перетащи
   папку из Finder прямо в чёрное окно: путь подставится сам. Потом Enter.

2. Поставь охранника на отправку копий:

```
bash scripts/nastroit-codex.sh
```

   В ответ будет две-три строки про охранника и сторожей. Слова «ошибка» среди них быть не должно.

3. Открой офис:

```
codex
```

   Программа спросит, доверяешь ли ты этой папке. Ответь **Yes**.

4. Набери `/hooks` и одобри оба пункта в списке.

   Шаг 3 пропускать нельзя. Пока папка не помечена доверенной, программа не подхватит
   настройки офиса: он будет выглядеть работающим, а помощников и правил у него не будет.
   Если в списке `/hooks` пусто - значит доверие не дали, вернись к шагу 3.
   Шаг 4 нужен для чёрного окна; панель и бот включают охрану сами.

5. Напиши «привет». Дальше офис ведёт тебя сам: поздоровается Технарь и доведёт установку
   до конца - бот, ключи, копии. Просто отвечай ему.

## Шаг 4. Кнопка «Офис» на рабочем столе (2 минуты)

Эту строку набери в Терминале, а не в разговоре с офисом: кнопка создаётся на рабочем столе,
а туда офису ходить нельзя. Разговор не закрывай, просто открой второе окно Терминала (⌘+N):

```
cd ~/Desktop/anna-kosmetolog-ofis
bash scripts/sozdat-knopku.sh
```

На рабочем столе появится значок «Офис». Двойной клик открывает панель офиса в браузере.
Дальше Терминал тебе почти не понадобится.

## Что офис доделает вместе с тобой в разговоре

- **Телеграм-бот офиса** - пульт к офису с телефона: кинула дубли, надиктовала правку
  голосом, получила черновик обратно.
  Важно знать: бот живёт на твоём маке. Мак спит или выключен - бот молчит, а всё, что ты
  написала, телеграм придержит до суток и отдаст офису, когда мак проснётся.
- **Ключи от сервисов** - пропуска к расшифровке звука и к картинкам. Ключи твои: заведём
  их вместе на первом созвоне, Технарь подскажет по шагам, где какой взять и сколько стоит.
- **Копии офиса** - чтобы работа не жила в одном экземпляре на одном ноутбуке.

## Что где лежит

- `results/` - готовые сценарии, посты, ролики. Всё, что ты показываешь людям
- `inbox/` - сюда кидай файлы: дубли, скриншоты статистики, тексты. Офис разберёт сам
- `plan/kontent-plan.md` - контент-план, его ведёт Продюсер
- `.env` - файл с ключами. Никому не пересылать, офис туда не заглядывает

## Про безопасность, честно

- офис не ходит в интернет без твоего разрешения, скачивать и подключать что-либо сам не может
- ключи и пароли лежат у тебя на маке, офис их никуда не отправляет
- единственное, что уходит наружу - звук твоих роликов на расшифровку, и только после «да»
- «утечь ничего не может» тебе никто не пообещает. Правда звучит так: на выходе стоит
  охранник, и всё личное он останавливает

## Если что-то не работает

Открой офис и напиши «не работает» и что именно. Технарь объяснит по шагам.
Если офис вообще не открывается, напиши Тарасу.
