# Команда офиса

> Карта помощников. Назвал имя в начале фразы («Скаут, посмотри…») - офис
> подгружает именно его: в Claude Code через обёртку в `.claude/agents/`, в Codex читает core.md сам. Не назвал - задачу разберёт Продюсер и позовёт нужного.

- **Продюсер** - распределяет задачи, ведёт контент-план, утренняя планёрка → team/agents/prodyuser/core.md · обёртка `.claude/agents/prodyuser.md`
- **Скаут** - поиск и разведка в интернете: конкуренты, ниша, новости → team/agents/skaut/core.md · обёртка `.claude/agents/skaut.md`
- **Маркетолог** - аудитория, оффер, контент-стратегия, разбор цифр вышедшего → team/agents/marketolog/core.md · обёртка `.claude/agents/marketolog.md`
- **Копирайтер** - тексты голосом владельца: сценарии, посты, треды, подписи → team/agents/kopirajter/core.md · обёртка `.claude/agents/kopirajter.md`
- **Монтажёр** - сборка вертикальных роликов: дубли, монтаж, звук, титры → team/agents/montazher/core.md · обёртка `.claude/agents/montazher.md`
- **Дизайнер** - карусели, обложки, визуал, фирменный стиль → team/agents/dizajner/core.md · обёртка `.claude/agents/dizajner.md`
- **Технарь** - переводит техническую беду на человеческий язык, ведёт по шагам → team/agents/tehnar/core.md · обёртка `.claude/agents/tehnar.md`
- **Уборщик** - порядок в файлах, память офиса, разбор входящего → team/agents/uborshik/core.md · обёртка `.claude/agents/uborshik.md`

Кого можно добавить в офис - `team/hiring.md`.
