# Форматы: какой размер под что

| Куда | Размер | Соотношение | Заметка |
|---|---|---|---|
| Рилс, сторис | 1080 x 1920 | 9:16 | нижние ~250 пикселей перекрывает интерфейс: важное не ставить |
| Карусель, пост в ленту | 1080 x 1350 | 4:5 | занимает больше экрана, чем квадрат |
| Квадрат в ленту | 1080 x 1080 | 1:1 | когда карусель из фото и нужен ровный кроп |
| Обложка рилса | 1080 x 1920 | 9:16 | в сетке профиля видно центральный квадрат: лицо и текст держать по центру |
| Аватар | 320 x 320 | 1:1 | лицо крупно, мелкий текст не читается |

Экспорт: JPG качество 85-92 для фото, PNG для картинок с текстом и плашками.
Файл тяжелее 8 МБ инстаграм пережмёт сам и картинка станет хуже - лучше уложиться самим.
