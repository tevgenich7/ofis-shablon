# Пропуска к сервисам - по шагам

> Справочник Технаря к этапу 6. Здесь пошагово, где взять каждый пропуск и как он
> называется в файле ключей. Ключи её собственные: заводит она сама, Тарас рядом на
> созвоне; шаги по одному за сообщение.
>
> **Проверено 16.09.2026.** Кнопки на сайтах иногда переезжают: если названия не сходятся
> с тем, что видит человек, не спорь и не выдумывай - попроси описать, что на экране.

## Железное правило про ключи

**Ключ никогда не вставляется в разговор с офисом.** Ни в панель, ни в чат, ни «просто
показать». Всё, что написано в разговоре, остаётся в истории и в логах.

Ключ кладётся в файл `.env` в корне офиса, одной строкой `ИМЯ=значение`. Кладёт она сама
(Тарас подсказывает на созвоне). Офис в этот файл не заглядывает и не пишет - ни ты, ни другие помощники.

Если она всё же прислала ключ в чат: скажи спокойно, что этот ключ теперь лучше отозвать
и выпустить новый, и покажи, где кнопка. Без нотаций, это обычная ошибка.

## 1. Расшифровка речи - Deepgram

**Зачем ей, одной фразой:** офис слышит, что сказано в её дублях и голосовых, и превращает
в текст. Без этого Монтажёр не знает, где что говорится.

**Цена:** первые сколько-то часов бесплатно, дальше меньше цента за минуту записи.

1. Открыть `console.deepgram.com`, зарегистрироваться почтой
2. Слева в меню - `API Keys`
3. Синяя кнопка `Create a New API Key`, название любое
4. Скопировать длинную строку - она показывается **один раз**
5. В `.env`: `DEEPGRAM_API_KEY=...`

**Проверка:** `python3 scripts/transcribe.py <любая запись>` выдаёт текст.

## 2. Картинки - Google AI Studio (Gemini)

**Зачем:** обложки, фоны, слайды каруселей. Это Дизайнер.

**Цена:** платно, бесплатного тарифа у картинок нет: в Google AI Studio должен быть
включён биллинг (привязана карта). По прайсу Google (сверено 31.07.2026, записано в
`generate-gemini.py`) картинка стоит от 3 до 13 центов в зависимости от модели.

1. Открыть `aistudio.google.com`, войти гугл-аккаунтом
2. Кнопка `Get API key` (обычно слева внизу или в шапке)
3. `Create API key` - выбрать проект или создать новый
4. В том же кабинете включить биллинг (`Billing`, привязать карту) - без него ключ есть,
   а картинок нет
5. Скопировать ключ
6. В `.env`: `GEMINI_API_KEY=...`

**Проверка:** `python3 .agents/skills/image-gen/scripts/generate-gemini.py -p "тест" -o /tmp/t.png`

## 3. Картинки посложнее - FLUX через fal (по желанию)

**Зачем:** когда нужна картинка уровня журнала или правка по образцу кадра.

**Цена:** около трёх центов за картинку, платится картой.

1. Открыть `fal.ai`, войти
2. В кабинете - `Keys` (или `API Keys`)
3. Создать ключ, скопировать
4. В `.env`: `FAL_KEY=...`

Не оплатили - не беда: Gemini закрывает большинство задач.

## 4. Стоки - Pexels, Unsplash, Pixabay

**Зачем:** перебивки в роликах и фоны. Бесплатно, все три разрешают коммерческое
использование.

**Pexels** (фото и видео):
1. `pexels.com/api`, войти или зарегистрироваться
2. `Get Started` → дать любое описание проекта
3. Ключ появляется сразу на странице
4. В `.env`: `PEXELS_API_KEY=...`

**Unsplash** (фото):
1. `unsplash.com/developers` → `Your apps` → `New Application`
2. Принять условия, назвать приложение
3. Со страницы приложения взять **Access Key**
4. В `.env`: `UNSPLASH_API_KEY=...`

**Pixabay** (фото и видео):
1. `pixabay.com/api/docs`, войти
2. Ключ показан прямо на странице документации
3. В `.env`: `PIXABAY_API_KEY=...`

**Проверка:** `python3 .agents/skills/stoki/scripts/stoki.py "face serum macro" --skolko 3`

## 5. Бот в телеграме

**Зачем:** пульт к офису с телефона.

1. В телеграме найти `@BotFather`, написать `/newbot`
2. Название любое, адрес должен заканчиваться на `bot`
3. Он пришлёт ключ - в `.env`: `TELEGRAM_BOT_TOKEN=...`
4. Она пишет своему боту любое слово
5. `python3 scripts/tg/chat-id.py` покажет её адрес - в `.env`: `ADMIN_CHAT_ID=...`

**Проверка:** `python3 scripts/tg/skazat.py "проверка"` - сообщение приходит ей в телеграм.

## 6. Гугл: таблицы, документы, формы, диск

**Зачем:** контент-план таблицей, сценарии документом, формы для клиентов, файлы на Диске.

Самый долгий пункт, минут двадцать. Подробности - `scripts/gugl/README.md`.

1. `console.cloud.google.com`, войти **её** аккаунтом, создать проект
2. `APIs & Services` → `Library` → включить четыре: Google Sheets API, Google Docs API,
   Google Drive API, Google Forms API
3. `OAuth consent screen`: тип `External`, заполнить название и почту, её адрес добавить
   в `Test users`, затем **`Publish app` → `In production`** (иначе доступ будет отваливаться
   каждые семь дней)
4. `Credentials` → `Create credentials` → `OAuth client ID` → тип `Desktop app`
5. Скачать файл, положить его в офис как `.mcp-sheets/credentials.json`
6. `bash scripts/gugl/postavit.sh` - соберёт окружение внутри офиса
7. `scripts/gugl/venv/bin/python3 scripts/gugl/avtorizaciya.py` - откроется браузер, войти
   её аккаунтом. Появится `.mcp-sheets/token.json`

**Проверка:** тот же `scripts/gugl/venv/bin/python3 scripts/gugl/avtorizaciya.py` - при живом
токене пишет «токен уже есть и действует» и проверяет боем: создаёт и тут же удаляет пробные
документ, таблицу и файл. Быстрая проверка без создания файлов: `scripts/gugl/proverka-prav.py`.

Офис получает доступ только к тем файлам, которые создал сам. В её Диск целиком
он не заглядывает - скажи ей это, вопрос возникает у всех.

## 7. Копии офиса - GitHub

**Зачем:** чтобы работа офиса не жила в одном экземпляре на одном ноутбуке.

1. Аккаунт на `github.com`
2. `New repository`, имя любое, обязательно **Private**
3. Ключ доступа: `Settings` → `Developer settings` → `Personal access tokens` →
   `Tokens (classic)` → `Generate new token`, права `repo`
4. В офисе: `git remote add origin <адрес репозитория>`
5. Разрешение на отправку: тот же адрес одной строкой в файл `team/ops/push-razreshen.txt`
   (пишет Тарас). Это охранник на выходе: `.git/hooks/pre-push` выпускает копию только по
   этому адресу, без файла или с другим адресом push останавливается
6. Первый `git push -u origin main`
7. Включить вечерний порядок: `bash scripts/vecher-postavit.sh`

С этого момента каждый вечер в 22:00 офис сам прибирается, пишет ей короткий отчёт
в телеграм и сохраняет копию.

**Что в копию не едет:** видео, фото, ключи. Видео тяжёлое, ключам в облаке не место.
Спроси один раз, где она хранит исходники роликов.

## Сводка: что как называется в файле ключей

| Строка в `.env` | За что отвечает | Без неё |
|---|---|---|
| `DEEPGRAM_API_KEY` | расшифровка речи | офис не слышит дубли |
| `GEMINI_API_KEY` | картинки | нет обложек и слайдов |
| `FAL_KEY` | картинки посложнее | обходимся Gemini |
| `PEXELS_API_KEY` | фото и видео со стоков | нет перебивок |
| `UNSPLASH_API_KEY` | фото со стоков | меньше выбора |
| `PIXABAY_API_KEY` | фото и видео со стоков | меньше выбора |
| `TELEGRAM_BOT_TOKEN` | бот офиса | нет пульта с телефона |
| `ADMIN_CHAT_ID` | кому бот пишет | бот не знает, кому отвечать |
| `OFFICE_AGENT=codex` | на чём работает офис | ищет наугад |

Гугл и GitHub ключей в `.env` не кладут: у них свои файлы (`.mcp-sheets/`) и своя
настройка через `git remote`.
