# Гугл в офисе: таблицы, документы, формы, диск

Что офис умеет: завести таблицу контент-плана, собрать документ со сценарием, сделать
гугл-форму, положить файл на её Диск и дать ссылку. Всё от имени владелицы, в её аккаунте.

## Как это включается (один раз, на этапе 6 установки)

Ведёт Технарь по `team/agents/tehnar/vneshnie-servisy.md`, раздел «Гугл». Если не выходит,
подключается Тарас.

1. Создать проект в Google Cloud на её аккаунте
2. Включить четыре API: Sheets, Docs, Drive, Forms
3. Экран согласия: тип «External», её почта в тестовые пользователи, потом опубликовать
   приложение (**Publish app → In production**) - иначе Google убивает доступ каждые 7 дней
4. Создать OAuth-клиент типа **Desktop app**, скачать файл и положить его сюда:
   `<офис>/.mcp-sheets/credentials.json`
5. `bash scripts/gugl/postavit.sh` - соберёт окружение внутри офиса
6. `scripts/gugl/venv/bin/python3 scripts/gugl/avtorizaciya.py` - откроется браузер,
   войти её аккаунтом. Появится `.mcp-sheets/token.json`, это и есть пропуск.
   Тот же скрипт сразу проверяет боем: создаёт и удаляет пробные документ, таблицу и файл

Скоуп один - `drive.file`: офис видит только те файлы, которые создал сам. В её Диск
целиком он не заглядывает, и это правильно. Всё своё офис держит в папке
«Офис - рабочие файлы» на её Диске (создаётся сама).

## Чем пользуемся

| Скрипт | Что делает |
|---|---|
| `gdisk.py` | основа: папка офиса на Диске, создать документ или таблицу, вкладки, записать, прочитать, загрузить файл |
| `sheets.py` | таблицы: обёртки над вкладками, список таблиц офиса |
| `docs.py`, `md2docs.py`, `zalit-dok.py` | документы: разметка, конвертер markdown, залить сценарий (создаст документ, если его нет) |
| `skachat-dok.py` | скачать документ обратно в офис (перед перезаливкой - обязательно) |
| `forma.py` | гугл-форма |
| `zagruzka-na-disk.py` | файлы на Диск и ссылки на них |
| `proverka-prav.py` | проверить, что доступ жив (ничего не создаёт) |
| `avtorizaciya.py` | вход её аккаунтом и проверка боем |

Запуск всегда через своё окружение: `scripts/gugl/venv/bin/python3 scripts/gugl/<скрипт>`.
Нет папки `scripts/gugl/venv` - сначала `bash scripts/gugl/postavit.sh`.

## Правило про правки

Если она правит документ в гугле, а офис потом перезальёт его целиком - её правки
затрутся. Поэтому перед любой перезаливкой сначала `skachat-dok.py`, и только потом
менять. Это не перестраховка, так уже теряли правки.
