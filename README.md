# ИИ-офис для блогера

Команда цифровых помощников, которая живёт папкой на компьютере: продюсер, маркетолог,
копирайтер, монтажёр, дизайнер, разведчик, технарь и уборщик. Панель в браузере, бот в телеграме,
память в файлах. Работает на Codex CLI.

Этот репозиторий - служебный слой офиса: помощники, панель, скрипты, охрана, инструкции.
Ничьих личных данных здесь нет и не появляется: работа владельца офиса живёт только на его
компьютере и в репозиторий не едет.

## Обновить установленный офис

```
bash scripts/obnovit.sh              # посмотреть, что изменится
bash scripts/obnovit.sh --primenit   # применить
```

Обновляются только служебные файлы. Тексты, ключи, память помощников и разговоры владельца
не трогаются; прежние версии заменённых файлов складываются в `karantin/`.

Что изменилось в последний раз - `team/ops/obnovleniya.md`.
